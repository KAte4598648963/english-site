# //english — специфікація сайту для занять англійською

> Коли з'являється команда **//english** або **/english**, Claude дотримується всіх правил нижче.
> Цей файл (CLAUDE.md) Claude Code читає автоматично на початку кожної сесії в цьому проєкті.

## 1. Структура
- Багатосторінковий сайт (одна оболонка, різні «сторінки» через маршрути, напр. `#/b1/module-2/lesson-3`).
- Ліве меню: 6 рівнів — A1, A2, B1, B2, C1, C2.
- Під кожним рівнем дропдаун (наведення / клік) зі списком модулів, у модулях — теми (уроки).
- Контент уроків додається поступово окремими файлами, сайт заново не створюється.

## 2. Сторінка уроку
- Відкривається як окрема сторінка всередині сайту.
- Справа зверху кнопка **«Запустити час уроку — 60 хв»** → маленький таймер (пауза, скидання).
- Зверху — лінія з кружечками-номерами вправ; клік переходить на вправу; виконані позначаються.
- Знизу кнопки **Назад** / **Далі**.

## 3. Вправи
- Інтерактивні, у стилі Duolingo + Quizlet: введення тексту, drag & drop, поєднання пар, вибір відповіді, флеш-картки тощо.
- Кожен урок має розділи на тему заняття: **Reading, Vocabulary, Grammar (rules + exercises), Listening, Writing, Speaking**.
- Кожен урок опрацьовуємо окремо.

## 4. Рівні C1–C2
- Суттєво відрізняються від A1–B2: фактично для власника сайту (просунутий рівень, складніші завдання, інша подача).

## 5. Дизайн
- Головне — зручність користувача.
- Приємний, продуманий, не різкий для очей і не чорно-білий (орієнтир — сайт підготовки до IELTS 8.5–9.0, але продуманіше).
- Адаптивність під телефон, світла/темна тема.

## 6. Панель інструментів уроку (A1–B2), справа зверху
1. **Перекладач (вкл/викл, за замовчуванням вимкнено)** — при наведенні на англійське слово спливає український переклад.
2. **Reset Lesson** — скидає прогрес саме цього уроку (з підтвердженням).
3. **Teacher mode** — показ правильних відповідей / підказок.
4. **Notebook** — нотатки до уроку.
5. **Vocabulary** — поле EN + поле UA → «Зберегти»; список зберігається в межах уроку.
6. **Export vocabulary & notes** — копіювання в буфер / поділитися; словник у форматі `dog - собака`, кожне слово з нового рядка.

## 7. Збереження прогресу
- Прогрес, відповіді, нотатки, словник зберігаються в браузері користувача (localStorage) і переживають оновлення та вихід із сайту.
- Кожна вправа має **постійний ID**; правки адміністратора в контенті не стирають і не змінюють уже виконане користувачем.
- Нові вправи в уроці додаються без втрати старого прогресу.

## 8. Деплой
- Хостинг: Vercel, **одна постійна адреса**.
- Оновлення йдуть у той самий проєкт Vercel (через GitHub або Vercel CLI), а не створенням нового проєкту → посилання не змінюється, прогрес користувачів зберігається.

## Технічна архітектура (для Claude)
- Статичний сайт без збірки: `index.html`, `css/`, `js/` (рушій: меню, маршрути, таймер, тулбар, типи вправ, збереження).
- Контент: `lessons/<level>/<lesson-id>.js` + реєстр `lessons/index.js` (рівні → модулі → уроки).
- Новий урок = новий файл + один рядок у реєстрі.
- Ключі збереження: `eng:<lessonId>:<exerciseId>`, версіонування схеми даних.

## 9. Зафіксований стан рушія (v1.0)
- Вигляд і механіка сайту затверджені власницею (коміт `2d425b7`; програвач Listening оновлено за запитом власниці). **Не змінюй `index.html`, `css/`, `js/`**, якщо вона прямо не попросила змінити дизайн чи механіку.
- Звичайна робота = лише нові/доповнені уроки в `lessons/` + рядки в `lessons/index.js`.
- Формат уроку і всі типи вправ описані в `lessons/README.md`; зразок — `lessons/b1/b1-m1-l1.js`.
- ID вправ не можуть починатися з `_` (зарезервовано: `_notes`, `_vocab`, `_pos`, `_timer`, `_summary`).
- У текстах уроків апостроф пиши як `’` (I’ve), щоб не ламати JS-рядки.
- Повноцінний урок: усі 6 розділів, 10–15 різнотипних вправ, правило з прикладами, словник для перекладача (A1–B2), перевірка в браузері перед комітом.
